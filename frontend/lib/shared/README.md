# Shared Layer

## Overview
The `shared` layer houses cross-cutting presentation primitives and reusable UI elements shared across feature modules in the RTConnect frontend client. It provides standardized, design-system-compliant components to prevent UI duplication and ensure visual consistency across both resident (`warga`) and RT administrator flows.

## Subdirectories & Boundaries
- widgets: [./widgets/README.md](./widgets/README.md) - Reusable UI primitives, form inputs, status badges, and navigation components grounded in Figma Hi-Fi tokens.
