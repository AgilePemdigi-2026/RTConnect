# Letters Feature

## Overview
Coordinates the live production letter administration system in RTConnect, supporting citizen letter requests, AI-assisted form population, official status auditing, RT review workflows, and digital/physical document ratification.

## Subdirectories & Boundaries
- `data`: [./data/README.md](./data/README.md) - Network repository and remote API client for letter lifecycle operations.
- `presentation`: [./presentation/README.md](./presentation/README.md) - Application forms, AI assistant screen, review screens, PDF viewer, controllers, and dialog widgets.
