# Profile Feature

## Overview
Coordinates user identity management, profile detail maintenance, avatar picture uploads, and digital signature configuration in RTConnect.

## Subdirectories & Boundaries
- `data`: [./data/README.md](./data/README.md) - Remote API client for profile updates, avatar uploads, and signature byte retrieval.
- `presentation`: [./presentation/README.md](./presentation/README.md) - Profile screen, edit profile form, signature canvas screen, and Riverpod controllers.
