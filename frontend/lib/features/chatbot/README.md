# Chatbot Feature

## Overview
Provides the Tanya RT intelligent citizen assistance subsystem, enabling conversational guidance on local neighborhood rules, letter prerequisites, and administrative escalation.

## Subdirectories & Boundaries
- `data`: [./data/README.md](./data/README.md) - Remote API client for querying the Tanya RT backend engine and retrieving session histories.
- `presentation`: [./presentation/README.md](./presentation/README.md) - Chat UI screens, conversation turn models, and Riverpod controllers for interacting with Tanya RT.
