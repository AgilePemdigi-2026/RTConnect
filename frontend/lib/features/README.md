# Features

## Overview
Organizes domain feature modules comprising the core business and user interface capabilities of the RTConnect Flutter mobile application, following clean layered architecture (presentation, domain, data).

## Subdirectories & Boundaries
- `auth`: [./auth/README.md](./auth/README.md) - User authentication, secure token storage, onboarding, and registration.
- `chatbot`: [./chatbot/README.md](./chatbot/README.md) - Tanya RT AI conversational assistance and administrative question answering.
- `home`: [./home/README.md](./home/README.md) - Role-specialized dashboard screens and status overviews for RT officials and warga.
- `letters`: [./letters/README.md](./letters/README.md) - Production letter administration lifecycle, AI form autofill, verification, and signing.
- `notifications`: [./notifications/README.md](./notifications/README.md) - System alerts, letter status update broadcasts, and unread counters.
- `pengajuan_rt`: [./pengajuan_rt/README.md](./pengajuan_rt/README.md) - Standalone demo module for RT submission review and PIN authorization.
- `profile`: [./profile/README.md](./profile/README.md) - Account profile management, avatar uploads, and digital signature configuration.
