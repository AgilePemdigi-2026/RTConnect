# Auth Feature

## Overview
Coordinates user authentication, session persistence, account onboarding, and authorization credentials for RTConnect residents and RT administrators across data, domain, and presentation layers.

## Subdirectories & Boundaries
- `data`: [./data/README.md](./data/README.md) - Remote API communication and secure storage persistence for authentication tokens and credentials.
- `domain`: [./domain/README.md](./domain/README.md) - Domain entities, data structures, and validation rules for identity numbers, passwords, and user profiles.
- `presentation`: [./presentation/README.md](./presentation/README.md) - UI screens and Riverpod state controllers for landing, login, registration, and session lifecycle.
