# Notifications Feature

## Overview
Coordinates real-time and persistent notification delivery, unread counter badges, and notification feed interactions across the RTConnect application.

## Subdirectories & Boundaries
- `data`: [./data/README.md](./data/README.md) - Remote API client for fetching notification items and updating read statuses.
- `presentation`: [./presentation/README.md](./presentation/README.md) - Notification feed UI screen, unread badge counter providers, and Riverpod controllers.
